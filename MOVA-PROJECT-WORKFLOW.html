MOVA Trading workflow

End-to-end map of how the MOVA prototype connects the user interface, browser state, API routes, external data providers and final market-intelligence views.

Resources and applications used

Front endSingle-file index.html, CSS, JavaScript routing, chart rendering, cards, search and page switching.
Backend / serverless/api routes act as the secure bridge between the front end and API providers. API keys belong in Vercel/Render environment variables.
Market dataTwelve Data provides live quotes and historical price data used in prices, movement charts and market status.
Company dataFinnhub provides company profiles, fundamentals and company news where configured.
NewsMarketAux or the configured news provider route supplies broader market, company, Nasdaq, commodity and macro headlines.
HostingGitHub stores the source. Vercel or Render deploys the static site plus serverless API routes.
Browser storagelocalStorage stores prototype account state, watchlist, alerts, wallet and portfolio data on the device.
Visual assetsThe /assets folder carries local files such as the Tesla hero background, brand visuals and learning images.
