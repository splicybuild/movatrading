# MOVA Trading v120 — Compare Brokers

Built from the user-amended `index(7).html` baseline.

## New Compare experience
- Desktop **COMPARE** tab between Tools and Portfolio.
- Mobile keeps the five-button bottom dock; Compare is available from **Tools → Compare Brokers**.
- Five comparison platforms: Trading 212, eToro, Freetrade, InvestEngine and interactive investor.
- No brokerage login, personal API key, portfolio connection or broker account scraping.
- MOVA market price remains the independent reference.
- Live executable broker quotes are deliberately not reproduced; users are directed to open their broker separately.
- Clickable `(i)` explanations for Commission, FX fee, Fractional shares, ISA, Account fees and Broker quote.
- Responsive broker cards and an illustrative investment-cost view.

## Published information
Platform characteristics are static comparison information and can change. Verify against each broker before relying on it.

## Deployment
Only `index.html` changed relative to your current user-amended baseline. The full package is supplied for convenience.
