# MOVA Trading v121 — Compare UX refinement

Built directly from the v120 Compare Brokers package.

## Changes

### Desktop
- The small `(i)` comparison buttons now work as **hover/focus tooltips**.
- Hover over Commission, FX fee, Fractional shares, ISA, Accounts, Live broker quote or MOVA reference price to read the explanation.
- Clicking the icon on desktop no longer opens a modal.

### Mobile
- **Compare Brokers is now genuinely embedded inside Tools.**
- It is the third Tools tab alongside Training Tools and A–Z Trading Jargon.
- Opening Compare on mobile keeps the five-button bottom navigation unchanged and keeps **Tools** as the active main navigation item.
- It no longer behaves like a sixth/separate mobile main page.
- Tapping an `(i)` icon on mobile still opens the readable information modal.

### Desktop navigation
- Compare remains a dedicated top-level desktop tab, as originally designed.

## Deployment
Only `index.html` changed from v120.
The ZIP includes the complete package for convenience.
