# MOVA Trading v123

Compare Brokers has been redesigned as a platform-positioning comparison rather than a live quote/cost comparison.

- MOVA is presented as research, education and decision-support before broker execution.
- Adds Discover → Research → Understand → Plan → Decide → Execute workflow.
- Adds six-platform feature cards: MOVA, eToro, Trading 212, Freetrade, interactive investor and InvestEngine.
- Adds capability matrix and visual MOVA Difference Map.
- Removes broker quote/reference-price and illustrative cost comparison widgets.
- No broker credentials, API keys or live broker quote scraping.
