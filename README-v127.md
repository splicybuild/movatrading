# MOVA Trading v127 — Full Working Market Explorer

This build is based on the full v126 working application and preserves the existing account/mobile welcome, Pulse, Tools, Learning Academy, Trading Jargon, Portfolio, News & Alerts, company research pages, watchlist and asset-detail workflows.

## v127 Home changes
- Visual-first **Top movers today** cards.
- **Explore markets** with Stocks, Indices, Commodities and Forex tabs.
- Recognisable logos for the company rows shown on Home. The existing v126 company-detail logo resolver remains in place for the broader company universe.
- Supported stocks, Nasdaq 100 and commodities open the existing full company/asset research page.
- MOVA short-analysis preview retained as research context rather than a buy/sell instruction.
- Existing global search remains available for the wider company universe.
- Desktop uses text navigation tabs aligned to the content; mobile retains the fixed icon navigation and existing welcome/sign-in landing.

Forex rows currently provide cross-asset context on Home; they do not pretend to be company research pages.
