# MOVA 2.0 — Phase 1 Tool-Focused Redesign

Baseline: user-supplied MOVA v125 index.html.

## Phase 1 changes
- Preserves the existing MOVA black / blue / green visual identity.
- Preserves the mobile welcome/login experience.
- Rebuilds Home as a tool-first dashboard instead of a marketing/information-heavy page.
- Adds six clear routes: Learn, Charts, Research, Analyse, Plan, Portfolio.
- Moves market content into a supporting "Market Context" role.
- Adds a dedicated Learn tab inside Tools.
- Adds six visual-learning module cards.
- Adds interactive scenario pop-ups with contextual feedback.
- Keeps Training Tools, Trading Jargon and Compare Brokers.
- Existing Pulse, research, portfolio, news and API systems remain in place.

## Deployment
Replace the existing project files with this package. The main UX change is in index.html; the remaining v125 project files are included so the package is deployable as a whole.

## Important
This is Phase 1 of the MOVA 2.0 learning redesign. The learning scenarios are deliberately a first functional prototype; full multi-step lessons, scoring, persistent progress and account-linked completion can be expanded in later phases after UX testing.
